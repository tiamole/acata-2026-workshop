Modernising Item Development with AI and LLMs
Minimal Worked Example Set for Participants
2. Prompt Pack: Minimal Worked Examples
Illustrative scenario: Secondary level science, applying Ohm's law. This example is for workshop practice only and is not tied to a specific examination board or national curriculum.
How to use this example
The prompts below show how to supply enough context for useful AI assistance while keeping professional judgment with the human item developer. Participants can copy the structure and replace the bracketed information with their own blueprint details.
Example 1: Generate one draft item
Sample prompt
You are assisting an assessment professional. Draft one four option selected response item using the specification below. Do not invent curriculum requirements.Construct: Application of Ohm's law in a simple direct current circuit.Learning outcome: Given voltage and resistance, calculate current using I = V/R.Cognitive demand: Apply.Content boundary: One resistor only. Use simple arithmetic.Language: Clear and concise.Fairness: Avoid irrelevant cultural context.Output: Stem, four options, answer key, rationale, and one sentence explaining the logic of each distractor.
Illustrative AI output
A simple circuit has a voltage of 12 V across a resistor of 4 ohms. What is the current in the circuit?
A. 0.33 A
B. 3 A
C. 8 A
D. 48 A
Key: B. Rationale: Current equals voltage divided by resistance, so 12/4 = 3 A. Distractor A may reflect reversing the division. Distractor C may reflect subtraction. Distractor D may reflect multiplication.
Human check: Confirm that each distractor is genuinely plausible for the target learners. AI can propose misconception logic, but that logic should not be treated as evidence until reviewed or supported by learner response data.
Example 2: Review alignment and cognitive demand
Sample prompt
Review the item against this intended outcome: Given voltage and resistance, calculate current using I = V/R. First identify what knowledge and reasoning the learner must use. Then judge whether the item directly measures the outcome and whether its cognitive demand is best described as recall, understand, apply, analyze, evaluate, or create. Explain your judgment. Flag any construct irrelevant difficulty. Do not rewrite the item unless a problem is found.
Minimal expected use
A useful response should identify that the learner must select the correct relationship and perform one division. The human reviewer then confirms whether this matches the intended construct and whether arithmetic complexity introduces any unintended demand.
Example 3: Bias and accessibility screening
Sample prompt
Screen this item for possible fairness and accessibility concerns. Consider unnecessary reading load, unfamiliar context, cultural or socioeconomic assumptions, ambiguous wording, avoidable sensory demands, and knowledge not required by the construct. Separate definite problems from possible risks. Do not claim that the item is unbiased. Recommend only changes that preserve the intended construct.
Minimal expected use
For this item, the reviewer might note that the context is minimal and does not appear to require culture specific knowledge. The phrase simple circuit should still be checked for consistency with prior instruction. Accessibility concerns appear limited because no visual is required. These are screening observations, not evidence that bias is absent.
Example 4: Distractor review
Sample prompt
For each incorrect option, state the possible error or misconception it is intended to represent. Flag any distractor that is implausible, overlaps with another option, can be eliminated through superficial clues, or is not supported by a reasonable error pathway. Suggest a replacement only when necessary.
Example 5: Final human verification prompt
Sample prompt
Act as a second reviewer, not the final decision maker. Identify any remaining concerns in content accuracy, construct alignment, cognitive demand, clarity, accessibility, fairness, answer key accuracy, distractor quality, and scoring. For every concern, state the evidence in the item that led to the concern. If no issue is found in a category, say no clear issue identified rather than declaring the item valid or unbiased.
